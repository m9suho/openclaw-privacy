# OpenClaw Privacy Policy

Last updated: 2026-10-20

## What OpenClaw is
OpenClaw is a private, single-user automation tool. It is used only by its owner, with the owner's own Google account.

## Data accessed
When the owner authorizes it, OpenClaw may access the owner's Google Calendar, Gmail, Drive, Docs, Sheets and Contacts data through Google APIs, only to perform automations the owner requests.

## How data is used and stored
- Data is processed on the owner's own computer.
- OAuth tokens are stored locally on the owner's device.
- Data is not sold, shared, transferred or disclosed to any third party, and is not used for advertising.

## Google API Services User Data Policy
OpenClaw's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

## Revoking access
The owner can revoke access at any time at https://myaccount.google.com/permissions.
